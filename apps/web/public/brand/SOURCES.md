# Visual assets and provenance

Updated 2026-09-06. Assets are served locally; no logo CDN, remote image allowlist, or third-party scripts are required at runtime.

## Agripinaa

The six orange hexagonal Bloub SVGs were supplied by the project owner, copied unchanged from Downloads into `public/brand/bloub/`. Header and footer cycle the five animated eye expressions, with a pause button and native reduced-motion still fallback. There is no standalone hero mascot. Neutral still is also the source for the registry image, favicon, Apple touch icon, and share card.

[Bloub](https://github.com/jeremy-prt/bloub), inspected at `b4bb3c1b5f93c7b87a2e8d620f667c4093d97749`. Copyright 2026 Jérémy Perret; MIT notice retained in `bloub/LICENSE`. Its README explicitly says the MIT licence covers the code, not the x.ai avatar design it imitates. This integration does not establish exclusive design/trademark rights; resolve that before adopting it as an exclusive commercial mark.

Run `pnpm --filter @agripinaa/web gen:icon` to regenerate all small brand images. The on-chain registration's `/agent-icon.png` URL is preserved.

The former CryptoLogos copies have been replaced with primary-source downloads. Original logo geometry and colors are unchanged. All marks use contain sizing and independent clear-space surfaces: shadows belong to the white surfaces, not the trademark artwork. USDC token glyphs render at least 32px. BNB's full horizontal logo is at least 97px. Full Aave wordmark is used to avoid pairing the ghost with an invented wordmark.

Protocol rows identify strategy venues, not partners, endorsements, or currently deployed balances. BNB is labelled “Built on.” BNB's guidelines request project approval; inclusion here does not claim that approval has been obtained. Protocol and token trademarks remain their owners' property and are not relicensed under Agripinaa's MIT licence.

BTCB uses Bitcoin's familiar mark but is always labelled BTCB (Binance-Peg Bitcoin), never native Bitcoin. WBNB uses the BNB mark with its WBNB label. BSC representations of stablecoins should not be taken as claims of native issuer deployment. Strategy assets come from the shared execution manifest, not the category's broad token list. Strategy protocols are pinned to first-party slugs, never owner-supplied text.

## 3D artwork

Eight original transparent PNG renders generated with the built-in imagegen tool (not the CLI), in `public/agents/{slug}.png`. Next/Image serves responsive optimized sizes; thumbnails request 64px. No brand marks were generated by AI. Decorative objects are not charts, account positions, forecasts, or proofs. Category icons reuse the corresponding render. Small control/status glyphs retain recognizable geometry with a beveled face and extruded edge.

### Final prompt set

Grid (`grid.png`):

> Use case: stylized-concept. Asset type: production website 3D strategy icon, single isolated object with genuinely transparent background. Primary request: a luxurious amber-gold modular grid of six solid rounded-edge cubes arranged as an elegant sculptural 3 by 2 matrix, floating in an isometric three-quarter view. Physically rendered 3D, polished anodized metal and warm satin ceramic, clearly visible thickness, soft studio key light from upper left, restrained reflections and ambient occlusion, crisp silhouette. Centered, full object visible, generous 15% padding, square canvas. Premium approachable financial application aesthetic, sophisticated not childish. No letters, text, logos, brands, charts, axes, watermark, background plate or checkerboard. Real transparent alpha.
